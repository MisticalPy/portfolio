## Sprint Task Tracker — fullstack pet-проект

Трекер задач в спринтах — основной проект лета, сделан с нуля как полноценное fullstack-приложение, а не учебный туториал.

### Стек
- **Backend:** Django, Django REST Framework
- **Frontend:** Vue 3
- **Асинхронные задачи:** Celery + Redis
- **Инфраструктура:** Docker, GitHub Actions (CI)
- **Auth:** JWT
- **Интеграции:** Anthropic API

### Идеи и фишки
- **JWT-аутентификация** вместо сессионной — осознанный выбор под SPA-архитектуру с отдельным Vue-фронтом
- **Celery + Redis** для фоновых задач — вынес долгие операции из request-response цикла (то, что в учебных проектах обычно опускают)
- **CI через GitHub Actions** — прогон тестов и линтеров при каждом пуше, а не "работает у меня локально"
- **Docker** — контейнеризация всего стека, воспроизводимое окружение
- **Интеграция с Anthropic API** — практика работы с внешним API третьей стороны в контексте бэкенда: аутентификация запросов, обработка ответов, обработка ошибок сети

### Чем отличается от учебного проекта
Это не пошаговое следование курсу, а самостоятельно спроектированная архитектура: свой roadmap, свои решения по разделению ответственности между Django и Vue, свой подход к деплою через Docker/CI. Показывает не просто знание Django, а умение собрать production-подобный пайплайн вокруг него.

## Kohi Anime — каталог аниме на Django

Первый крупный проект — сделан в рамках прохождения Django-курса (Яндекс, ~3 месяца, февраль–май). Каталог аниме с фильтрами, пользовательскими профилями и кастомной админкой.

### Стек
- **Backend:** Django
- **Frontend:** Django Templates + Bootstrap
- **Инфраструктура:** CI/CD (flake8, black, pep8), разделение зависимостей prod/test/dev

### Идеи и фишки
- **Архитектура с нуля:** несколько Django-приложений, `.env`-конфигурация, разделённые зависимости под разные окружения
- **Кастомный Middleware** — нестандартная логика на уровне обработки запросов/ответов (каждый 10-й ответ переворачивает русские слова) — демонстрирует понимание того, как работает request/response cycle в Django, а не только "из коробки"
- **Модели с валидацией и связями** — `Item`, `Tag`, `Category` с кастомными валидаторами
- **Кастомизация Django Admin** — `list_display`, `list_editable`, `filter_horizontal`, локализация интерфейса под русский язык
- **Расширение модели пользователя** через профиль 1:1 (`Profile`) — регистрация, вход, редактирование профиля, аватары
- **ORM-запросы под конкретные бизнес-задачи** — QuerySet'ы с фильтрацией по флагам публикации и вывода на главную страницу
- **CI/CD с первого дня** — flake8, black и pep8-плагины в пайплайне, а не добавлены постфактум

### Статус
Учебный проект, доведённый до рабочего состояния (каталог, фильтры, профили, админка, дизайн). Осознанно не продолжен дальше — стал стартовой точкой для перехода к более серьёзному fullstack-проекту (Sprint Task Tracker), где решения уже принимались самостоятельно, а не по структуре курса.

## Как это использовать в сопроводительном

Логика подачи: Kohi Anime показывает, что база Django освоена системно (модели, ORM, admin, middleware, CI) — это был учебный этап. Sprint Task Tracker показывает шаг дальше: самостоятельная архитектура, асинхронность (Celery/Redis), контейнеризация, интеграция внешнего API — то есть переход от "прошёл курс" к "могу спроектировать и держать целый сервис".
